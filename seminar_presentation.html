Implementation

الكود البرمجي للتجربة (C++ Source Code)

Standard C++11/17/20 
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. مصفوفة ثابتة الحجم تحتوي 15 اسماً
    string names[15] = {
        "Ali", "Ameer", "baqer", "bhaa", "fras", 
        "fars", "jafer", "banen", "rouqia", "aseil", 
        "farhan", "zaid", "ahmed", "fatema", "mohammed"
    }; 
    int n = 15;   

    // 2. خوارزمية الفرز الفقاعي (Bubble Sort)
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            // مقارنة معجمية حرفاً بحرف عبر ASCII تلقائياً
            if (names[j] > names[j + 1]) {
                string temp = names[j];
                names[j] = names[j + 1];
                names[j + 1] = temp;
            }
        }
    }

    // 3. طباعة الأسماء بعد الترتيب
    cout << "--- Sorted Names) ---\n";
    for (int i = 0; i < n; i++) {
        cout << names[i] << endl;
    }
    return 0;
}

Algorithm Mechanics

آلية عمل الفرز الفقاعي (Bubble Sort)

كيف ترتفع الأسماء الأكبر نحو القمة خطوة بخطوة؟

1

الحلقة الخارجية (i Loop)

for (i = 0; i < n - 1)

تحدد عدد الجولات الكلية (Passes). نحتاج إلى 14 جولة لترتيب 15 اسماً بالكامل.

2

الحلقة الداخلية (j Loop)

for (j = 0; j < n - i - 1)

تقوم بالمقارنة بين جارين متلاصقين names[j] و names[j+1] وتقل نطاقاً مع كل جولة.

3

عملية التبديل (Swapping)

temp = A; A = B; B = temp;

إذا كان الاسم الحالي أكبر أبجدياً من الذي يليه، يتم التبديل مباشرة لضمان التقدم الصحيح.

Under The Hood

سر مقارنة النصوص: محرك الـ ASCII الداخلي في C++

كيف يتعامل المعالج ومترجم C++ مع الكلمات خلف الكواليس؟

⚙️

المقارنة المعجمية التلقائية (Lexicographical Comparison)

عند كتابة names[j] > names[j+1]، يقوم مشغل المقارنة المدمج في فئة std::string بإجراء فحص حرف-بحرف (Character-by-Character) دون الحاجة لدوال تحويل يدوية.

🔢

التحويل الرقمي الصامت لقيم ASCII

كل حرف يُخزن كبايت (Byte) يحمل قيمة رقمية مطابقة لجدول ASCII القياسي. عندما يقارن الحاسوب حرفين، فإنه في الواقع يطرح القيمتين الرقميتين في مسجلات المعالج (CPU Registers):

'A' = 65 (DEC) مقارنة مع 'a' = 97 (DEC) ➔ 65 < 97
🎯

حالة تشابه الحروف الأولى (Tie Breaking)

إذا تطابق الحرف الأول (مثلاً بين Ali و Ameer الحرف الأول هو 'A' بقيمة 65)، ينتقل الفحص تلقائياً للحرف الثاني: حرف 'l' (108) مقابل حرف 'm' (109). وبما أن 108 < 109 فإن كلمة "Ali" تسبق "Ameer"!
